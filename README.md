Project Overview
Mutumane Kota 'N' Grilled Chicken is a bold, energetic web application designed to showcase authentic South African township street food. The platform provides an interactive digital storefront featuring comprehensive menus, local kitchen contact details, online delivery ordering forms, and general enquiry handling. The project emphasizes responsive design, structured layouts, and vibrant visual styling inspired by traditional flame-grilled flavours.

Website Goals and Objectives
Digital Presence: Establish a professional online identity for a local fast-food brand.
User Engagement: Provide clear navigation across multiple pages, including Home, Menu, Orders, About, Contact, and Enquiry.
Convenience: Streamline the ordering and customer feedback process through intuitive, accessible form interfaces.
Responsive Accessibility: Deliver a seamless visual experience across desktops, tablets, and mobile devices with fluid card grids and touch-friendly controls.

Key Features and Functionality
Multi-Page Architecture: Connected HTML templates (`index.html`, `menu.html`, `orders.html`, `aboutUs.html`, `contact.html`, `enquiry.html`) sharing a unified external stylesheet.
Unified Design System: Distinct visual branding utilizing a warm charcoal Gray background (`#1E1E1E`), fiery orange accents (`#E65100`), and warm yellow highlights (`#FFB300`).
Interactive Menu Grid: Equal-height card components featuring image zoom transitions on hover/touch and structured numbered lists for menu items.
Online Order & Enquiry Forms: Fully styled input fields, radio button groups, checkboxes, and textareas optimized for both desktop and mobile tapping.

Timeline and Milestones
Phase 1 (Concept & Wireframing): Brand identity development, colour palette selection, and initial page structure layout.
Phase 2 (Core Development): Implementation of core HTML templates and external CSS styling for the home, menu, and contact pages.
Phase 3 (Refinement & Responsiveness): Integration of media queries, mobile background layouts, flexbox grid alignment, and form enhancements.
